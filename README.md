## 滴水三期 · 14 天精简执行计划

**总节奏**：每天 3–5 小时；概念讲解 2 倍速，栈帧、PE、脱壳这类实操 1 倍速慢慢跟；铁律是“看 30 分钟课，必须动手 15 分钟”——写 C、单步调试、读 PE 结构，千万别只看视频。

### 第 1 周 · 打底（汇编 → C → C++ 反汇编）

**D1｜进制、数据宽度、逻辑运算 + 通用寄存器、标志位（ZF/SF/CF/OF）**
概念课开 2 倍速刷过即可，重点是自己在调试器里看一次标志位翻转。跳掉冷门指令和 8086 实模式历史科普。

**D2｜内存寻址方式 + 常用指令（mov/push/pop/call/ret/jmp 系列）**
这条是后面所有东西的砖，别跳。逐条在 x64dbg 里单步验证每个指令干了什么。

**D3｜栈原理 · 栈帧 EBP/ESP · 函数调用全过程** **⭐⭐⭐****（必啃）**
全路线最值钱的一天。写一个带参数、带局部变量的 C 函数，单步跟 call → push ebp → 开栈 → 返回的完整过程，亲眼看着 ESP/EBP 怎么动。
🎯 **验收**：能徒手画出一段函数调用栈的变化，并讲清“为什么缓冲区溢出能覆盖返回地址”。这一关过了，PWN 的根就扎下了。

**D4｜C 反汇编：局部/全局变量 + 数组、指针** **⭐⭐⭐**
自己写小程序（int、数组、指针传参各一个），编译成 32 位，反汇编对照。这是逆向看代码的核心手艺。

**D5｜C 反汇编：if / for / switch**
重点看 switch 的跳表（case 多了编译器会建跳转表）和循环的 jcc 结构。

**D6｜函数、参数、返回值、堆栈平衡（cdecl/stdcall）****⭐⭐⭐** **+ 结构体**
写两种调用约定对比，看调用者平衡栈和被调用者平衡栈的区别——后面看病毒、看 IAT、看注入都会用到。
🎯 **验收**：随手一个简单 C 函数，能默写出它的反汇编骨架。跳掉和汇编无关的复杂 C 语法。

**D7｜C++ 反汇编：this 指针、类、成员函数**
写个类，看成员函数怎么把 this 塞进 ecx。

**D8｜虚函数、虚表** **⭐⭐** **+ Win32 进程/线程基础概念（半天）**
看类带虚函数后多出来的那 4 字节 vfptr、虚表查址的 call。跳过多重继承/菱形继承/模板反汇编，入门用不上。
🎯 **验收**：反汇编里能认出“这是 this 调用”“这走了虚表”。

### 第 2 周 · 攻坚（Win32 → PE → 脱壳 → 接 PWN）

**D9｜Win32 内存 API：VirtualAlloc / VirtualProtect** **⭐⭐**
shellcode、注入、脱壳里全是这两个。动手写个分配内存的 demo，看反汇编里它的三个关键参数（地址/大小/保护属性）。窗口 GUI、按钮、消息循环整套直接快进，PWN 用不上。
🎯 **验收**：能看懂注入/脱壳代码里“申请内存 + 改保护属性”那几步。

**D10｜PE 结构：DOS 头 MZ → NT/PE 头（ImageBase、OEP）→ 节表（.text/.data/.rdata）****⭐⭐⭐**
脱壳核心，必啃。拿一个真实 exe 用 CFF Explorer 对照着看，别只盯视频。

**D11｜导入表 IAT、导出表 EAT** **⭐⭐⭐** **+ 重定位表**
Scylla 修复 IAT 修的就是这个。看一个程序调 MessageBox 时 IAT 里存的真实地址。跳掉冷门 PE 扩展字段。
🎯 **验收**：用 CFF Explorer / 010Editor 完整讲清一个 exe 的头、节表、导入表。

**D12｜壳是什么、加壳原理 + UPX 压缩壳手动脱壳**
先搞懂“壳 = 一段先执行的解压代码”，再跟着脱 UPX。

**D13｜ESP 定律找 OEP → x64dbg 动态 dump → Scylla 修复 IAT** **⭐⭐⭐**
应用层收官战。多找几个 UPX 加壳样本练手，直到闭着眼能走完流程。VMP/Themida 只了解原理，不死磕。
🎯 **验收**：独立完成“加壳 → 找 OEP → dump → 修 IAT → 程序能跑”全流程。

**D14｜收尾 + 接 PWN**
半天查漏补缺，半天把滴水没讲的补齐：x64 调用约定（RCX/RDX/R8/R9 + 影子空间）、Linux ELF、System V ABI（rdi/rsi/rdx 传参），然后跑通第一个本地栈溢出 exp。
🎯 **验收**：滴水应用层闭环，正式进入 PWN。

## 看完滴水后的 PWN 入门清单（Day 14 起衔接）

按这个顺序走：**环境**（Ubuntu 虚拟机/云机 + pwntools + gdb/pwndbg）→ **栈溢出原理**（滴水栈帧就是根基；再学 canary/NX/PIE/RELRO 各防线）→ **ROP**（gadget 收集、ret2text / ret2shellcode / ret2libc）→ **工具链**（checksec、cyclic、one_gadget、LibcSearcher）→ **刷题**（BUUCTF → pwnable.tw → 攻防世界）→ **进阶**（格式化字符串、堆利用，后置再啃）。
