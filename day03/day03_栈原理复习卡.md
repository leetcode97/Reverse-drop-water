## 1. 一张必须刻进脑子的图（32 位，add(int a, int b) 执行中）

```
高地址
  ┌──────────────┐ 0x1010  main 的返回地址（回 CRT）
  ├──────────────┤ 0x100C  main 保存的 EBP
  ├──────────────┤ 0x1008  （main 帧内，对齐）
  ├──────────────┤ 0x1004  （main 帧内）
  ├──────────────┤ 0x1000  ← EBP（main 帧基址）
  │   x = 3      │ 0x0FFC  [ebp−4]
  │   y = 4      │ 0x0FF8  [ebp−8]
  │   z          │ 0x0FF4  [ebp−12]
  ├──────────────┤ 0x0FF0  参数槽 b = 4   （ebp+12）
  ├──────────────┤ 0x0FEC  参数槽 a = 3   （ebp+8）  ← ESP（main 调用前）
  ├──────────────┤ 0x0FE8  返回地址（call 压入）
  ├──────────────┤ 0x0FE4  ← EBP（add 帧基址）· 保存的 main EBP
  │   sum = 7    │ 0x0FE0  [ebp−4]        ← ESP（add 开栈后）
  └──────────────┘ 低地址
```

口诀（四幕）：
1. **传参**：32 位实参压栈（右→左），call 把返回地址压栈；
2. **建帧**：`push ebp`（保存调用者帧）→ `mov ebp, esp`（新帧基址）→ `sub esp, N`（局部空间）；
3. **访问**：参数 `[ebp+8]` 起，局部 `[ebp−4]` 往下；
4. **收帧**：`leave`（= mov esp,ebp + pop ebp）→ `ret`（= pop eip），栈完全复原。

## 2. 为什么缓冲区溢出能覆盖返回地址（一句话版）

`ret` 的语义就是**无条件信任栈上 `[ebp+4]` 那 4 个字节当作下一条指令地址**；
`strcpy(buf, s)` 这类无边界写会从低地址（buf）一路向高地址写，
而返回地址恰好就躺在 buf 上方——先越过 16 字节的 buf，再越过 4 字节的保存 EBP，**第 21 个字节起正好改写返回地址**；
函数一 `ret`，CPU 就把你写进去的“数据”当成“下一条指令地址”跳走 → 崩溃 / 劫持执行流。

## 3. 溢出边界速记（32 位，buf[16] 在 ebp−16）

| 输入长度 N（不含 \0） | 写到哪里 | 后果 |
|---|---|---|
| ≤ 15 | 全在 buf 内 | 安全 |
| 16 | 写满 buf，\0 落在保存 EBP 第 1 字节 | 临界，差 1 字节越界 |
| 17–20 | 覆盖保存的 EBP | leave 恢复帧基址时 EBP 被污染 |
| 21–24 | **覆盖返回地址** | **ret 时 EIP 被劫持 → 崩溃/执行任意代码** |
| ≥ 25 | 继续向上写穿 main 的帧 | 完全失控 |

64 位差异：槽位都是 8 字节，返回地址在 rbp+8；前 17–24 字节毁 saved RBP，25 字节起毁返回地址（本机 gdb 实测：32 个 `A` → rbp 与 ret 槽全为 `0x4141414141414141` → SIGSEGV）。

## 4. 验收自测（能答出即过关）

1. 不查资料，画出 `f(int a){int x; ...}` 被调用时 EBP/ESP 从调用前到返回后各落在哪个相对位置？
2. `call` 和 `ret` 各自对栈做了什么？（压/弹什么，ESP 各 ±多少）
3. 为什么越界写一定“向上”覆盖返回地址，而不是向下？（栈向低地址生长，buf 在低地址，返回地址在 buf 高地址侧）
4. `leave` 为什么能恢复调用者帧？（它先弹掉局部空间，再弹出保存的 EBP，两个动作恰好对称于建帧）

## 5. 验收自测答案（默写版，2026-09-08 过关）

1. **帧槽位**（单参数 `f(int a)`，32 位）：`[ebp+8]`=参数 a，`[ebp+4]`=返回地址，`[ebp+0]`=保存的 EBP，`[ebp-4]`=局部 x；`[ebp+12]` 是第二个参数位（双参数版才用）。
2. **call/ret 对称**：call 只压返回地址，ESP−4；ret 只弹返回地址，ESP+4；ret 弹的就是 call 压的那个，一来一回完全复原。
3. **溢出因果链（四步）**：① 返回地址先被压入 → 住最高地址；② 局部 buf 后开 → 住最低地址；③ strcpy 从 buf[0] 往 buf[15]、再往后 = 地址一路增大 = 朝着返回地址走；④ 写得够长（越界）→ 撞上返回地址。
4. **leave 的对称性**：建帧 = `push ebp`（存旧桩）+ `mov ebp,esp`（钉新桩）+ `sub esp,N`（开局部）；收帧 = `mov esp,ebp`（ESP 拉回界桩，抵消 sub esp）+ `pop ebp`（弹回旧桩，抵消 push ebp）。压入顺序 参数→返回地址→旧EBP→局部，弹出顺序正好反过来（LIFO）。

> 本机 gdb 实弹（64 位，buf 在 rbp−16）：23 个 A → 保存 EBP 被毁，返回地址槽原样 `0x00007ff64edc1520`；25 个 A → 第 25 字节起侵入返回地址，槽变 `0x00007ff64edc0041`（低字节 0x20→0x41）。与速记表"25 字节起毁返回地址"完全一致。
