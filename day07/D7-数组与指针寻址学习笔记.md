# D7 学习笔记：数组与指针寻址

## 1. 数组 = 连续内存 + 下标换算偏移

数组在内存里就是一排挨着的格子（int 每个 4 字节）。找第 i 个：**首地址 + i×4**。

```
a[0] a[1] a[2] a[3]
+0   +4   +8   +12     ← 每个元素间隔 4 字节（int 大小）
```

真实产物（sum_arr 循环体，三步算出 a[i]）：

```asm
lea  rdx, [rax*4]      ; ① 下标 × 4（rax = i）★ 数组铁证：乘的元素大小
mov  rax, [rbp+0x10]   ; ② 取出数组首地址 a
add  rax, rdx          ; ③ 首地址 + 偏移
mov  eax, [rax]        ; ★ 取出 a[i] 的值
```

**铁证识别法**：反汇编里看到 `[寄存器×4]`（×2/×4/×8）这种"乘比例"寻址 = 数组下标访问，比例数就是元素大小（int 数组 ×4，指针数组 ×8）。

main 里数组的初始化（每个元素一条 mov，间隔 4 字节）：

```asm
mov  DWORD PTR [rbp-0x20], 0xa   ; arr[0] = 10
mov  DWORD PTR [rbp-0x1c], 0x14  ; arr[1] = 20
mov  DWORD PTR [rbp-0x18], 0x1e  ; arr[2] = 30
mov  DWORD PTR [rbp-0x14], 0x28  ; arr[3] = 40
lea  rax, [rbp-0x20]             ; rax = &arr[0]（数组名 = 首地址）
```

---

## 2. lea vs mov：抄地址 vs 取东西

| 指令 | 做的事 | C 对应 |
| --- | --- | --- |
| `lea rax, [rbp-0x20]` | **抄地址**：把"rbp-0x20 这个地址"算出来放进 rax，**不读内存** | `&arr[0]`（取地址） |
| `mov eax, [rbp-0x20]` | **取东西**：跑到那个地址把 4 字节值拿出来 | `arr[0]`（取值） |

**为什么 lea 有用**：它能用"地址算式"做算术——

```asm
lea rdx, [rax*4]            ; = rdx = rax×4（乘法！）
lea rax, [rax+rdx*4+8]      ; = 一次算完 基址 + 索引×4 + 偏移
```

口诀：**lea 只算不去，mov 才真的去**。

---

## 3. 指针 = 地址的间接访问（解引用）

指针变量 p 自己不长数据，只记一件事：**东西在哪个柜子**（一个地址）。

- `*p`（解引用）= 按便利贴去柜子拿东西 = 先 `mov rax,[p]`（取出地址）再 `mov eax,[rax]`（去读值）
- `p++` = 把便利贴上的柜号改到下一格（int 加 4）

真实产物（sum_ptr 循环体）：

```asm
mov  rax, [rbp+0x10]   ; ① 取出便利贴：rax = p（一个地址）
lea  rdx, [rax+0x4]    ; ② 算下一格：rdx = p + 4
mov  [rbp+0x10], rdx   ; ③ 改便利贴：p = p + 4（p++）
mov  eax, [rax]        ; ★ 按旧便利贴取东西：eax = *p（解引用！）
add  [rbp-0x4], eax    ; s += *p
```

对照 D6：结构体传指针 `sum_p` 里的 `mov edx,[eax]`（p->x）就是同一个动作——**按指针的地址读值**。

## 4. 数组 vs 指针：核心对照

| | 数组 `a[i]` | 指针 `*p` |
| --- | --- | --- |
| 地址从哪来 | **编译器用公式算**：首地址 + 下标×4 | **存变量里**：从 p 取出来 |
| 访问方式 | 随机访问，一步到位（a[5] 直接算，不路过 a[0..4]） | 存哪指哪（可指向数组中间、别的数组） |
| 遍历 | for 循环 i++ 让它逐个走（是循环的锅，不是数组只能逐个！） | p++ 改便利贴逐个走 |
| 底层动作 | 先得到地址 → `mov [地址]` 取值 | 先得到地址 → `mov [地址]` 取值 |

**一句话**：数组 = 公式算位置（基址固定）；指针 = 便利贴找位置（地址是变量）。底层都是**先地址、再取值**，所以 C 里 `a[i]` 和 `*(a+i)` 完全等价。

---

## 5. 踩过的坑（重点记住）

- **"数组只能一个一个跳"是误区**：数组是随机访问（公式一步到位）；"逐个"是 for 循环 i++ 造成的，不是数组的特性。
- **lea 是算地址不读内存**：`lea rax,[rax*4]` 结果是"下标×4"这个偏移数字，不是去读东西。
- **rbp 是量尺，不是数组起点**：数组首地址 a 存在 `[rbp+0x10]`（参数槽）里，要先取出来再用。

## 6. 答辩题（含答案，用于自查）

1. `a[5]` 的地址怎么算？→ 首地址 a + 5×4 = a + 20。
2. `lea rax,[rax*4]` 执行后 rax 里是什么？→ 下标 i 的 4 倍（一个偏移数字），i=5 则 rax=20；不是"地址的 4 倍"。
3. `sum_ptr` 里 `mov eax,[rax]` 对应 C 的什么？→ 解引用 `*p`（按 p 存的地址去读值）。
4. 数组 `a[i]` 和指针 `*p` 找元素的方式有什么不同？→ 数组公式算地址（随机访问一步到位）；指针地址是变量（存哪指哪）；底层都是"先地址、再 mov 取值"。
5. 数组是"只能一个一个跳"吗？→ 不是。a[3] 直接 = 首地址+3×4，不路过 a[0]~a[2]；"逐个"是 for 循环 i++ 造成的。
