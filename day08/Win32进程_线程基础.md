# 进程和线程
进程是资源分配的最小单位

线程是调度的最小单位



# 多线程共享内存就会产生竞争
有竞争---------》就得有锁（mutex互斥信号量）

从而产生线程隔离



# 虚拟内存和进程隔离
虚拟内存就是每个进程自己的地址表（相当于一个自己进程的别墅地图）



进程隔离就是各个进程相互分离，不知道对方存在，地址分布相同，同一地址码在不同进程中内容不同



# 注入信号
+ `VirtualAllocEx`：在目标进程地图上划一块地
+ `WriteProcessMemory`：把自己的代码写进去
+ `CreateRemoteThread`：在目标进程里派一个线程跑这段代码

**逆向时看到这三个 API 连用 = 注入信号。**（拦截函数同理：先找到那栋别墅里函数住哪——IAT。）
